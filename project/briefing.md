# Activity Bookings Client

Build a client for the Activity Bookings demo API.
Users can discover scheduled activities and view their details.
Users can register and log in with email and password.
Authenticated requests use the API's JWT token.
Users can book participants for an activity.
The API enforces participant capacity and simulates payment.
Users can view their bookings and payment status.
The API runs locally at `http://localhost:3000`.
See the API README and specifications for setup and endpoints.
The client may be a web app or terminal app.
Language and framework are open choices.
The API uses TypeScript, Express, JWT, JSON files, and mock payments.
This project is for demos and training, not production use.
